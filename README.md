# 📊 Criando uma Ferramenta de Controle de Investimentos com Excel

Projeto desenvolvido durante o curso **"Criando uma Ferramenta de Controle de Investimentos com Excel"**, da [DIO](https://www.dio.me/).

A proposta do projeto foi desenvolver uma ferramenta em Excel para auxiliar no **controle e planejamento de investimentos**, utilizando recursos de organização de dados, fórmulas e visualização de informações.

## 🎯 Objetivo

Criar uma planilha funcional que permita ao usuário organizar informações relacionadas aos seus investimentos e visualizar projeções de forma mais clara, facilitando o acompanhamento e o planejamento financeiro.

## 🛠️ Tecnologias e recursos utilizados

* **Microsoft Excel**
* Fórmulas e funções do Excel
* Organização e tratamento de dados
* Tabelas
* Formatação condicional
* Validação de dados
* Cálculos financeiros
* Visualização e análise de informações

## 📌 Funcionalidades

A ferramenta foi desenvolvida para permitir:

* Organização dos dados de investimentos;
* Definição de valores para investimento;
* Simulação de diferentes cenários;
* Cálculo de projeções financeiras;
* Visualização dos resultados;
* Apoio à tomada de decisões relacionadas ao planejamento de investimentos.

## 📚 Principais aprendizados

Durante o desenvolvimento do projeto, pratiquei:

* Estruturação de planilhas para resolver problemas reais;
* Utilização de fórmulas para automatizar cálculos;
* Organização e análise de dados no Excel;
* Criação de ferramentas interativas;
* Aplicação de conceitos financeiros em uma solução prática;
* Construção de uma interface mais organizada e intuitiva para facilitar a utilização da planilha.

## 💡 Sobre o projeto

Este projeto faz parte da minha jornada de aprendizado em **Dados, Excel e Inteligência Artificial**, buscando desenvolver habilidades práticas para transformar dados em informações úteis e soluções aplicáveis ao dia a dia.
